About

I am a Senior Staff Researcher at Huawei, working on foundation models, agent algorithms, and industrial AI systems for EDA. My recent work focuses on building reliable agentic systems for formal verification and testing, including SAT-based reasoning, RTL code generation, bug finding, verifier-guided optimization, and self-evolving agents.

My research background spans machine learning, numerical optimization, combinatorial optimization, and industrial verification. I have worked on AI-augmented SAT solvers, data augmentation for EDA, LLM-driven Verilog generation, agent training and deployment, long-context modeling, and post-training methods for reasoning and tool-using agents.

Research Interests

  1. AI/LLM for EDA. Developing AI-augmented solvers and modeling methods for industrial EDA applications, including logic synthesis, ATPG, LEC, testbench generation, model checking, and bug finding.

  2. Code Generation and Verifier-Guided Agents. Building RTL code generation systems and code agents that use trace-to-root-cause reasoning, patch ranking, verifier feedback, and downstream task signals.

  3. Industrial Agent Systems. Training and deploying agents for industrial verification tools, with emphasis on tool invocation, memory, multi-agent collaboration, execution-time recovery, and continuous improvement from interaction traces.

  4. Agentic RL and Post-Training. Designing reward models, rollout optimization, process-aware supervision, long-context training, memory internalization, speculative decoding, and training-inference co-design for reasoning and agent models.

Selected Projects

  • LLM and Agents for Industrial EDA

    • Developed industrially viable AI-driven SAT solving and data augmentation methods for formal verification and testing. These systems support real chip scenarios such as ATPG, LEC, bug finding, and model checking, and help bridge conventional mathematical modeling with language-model-based reasoning.

    Led customized LLM-driven EDA tools since 2022, including Verilog generation and bug finding. The work combines solver feedback, circuit structure, and language model reasoning to improve practical verification workflows.

  • Industrial-Grade Agent Training and Deployment

    • Built and maintained agent systems for formal verification, bug finding, code review, and deep research. The systems cover tool invocation, collaborative reasoning, recovery from execution-time failures, and tool fusion over solver APIs.

    Developed self-improvement loops using supervised fine-tuning and GRPO-style updates, enabling agents to learn from interaction traces while reducing reliance on centralized raw-data collection. I also studied production failure patterns across model behavior, prompt design, tool use, memory, multi-agent coordination, and system scheduling.

  • Agentic RL and Training-Inference Co-design

    • Designed post-training pipelines for large reasoning and agentic models under fixed compute budgets, including difficulty-aware reward shaping, pass@k training, adaptive compute allocation, verifier-based optimization, and dense reasoning supervision.

    Explored long-context and memory-internalized training for agent tasks, as well as speculative decoding and quantization techniques for improving training and inference efficiency.
